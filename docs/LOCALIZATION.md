# Interface localization

The editable sources are `Shared/Resources/Localization/<language>.json`. Supported languages are English, Simplified Chinese, Traditional Chinese, Japanese, Korean, Russian, French, and Spanish.

Each catalog contains three sections:

- `strings`: shared messages, preserving existing Apple English keys and interpolation placeholders.
- `plurals`: Apple plural definitions, including the categories required by each language.
- `windows`: Windows-only messages and overrides for system terminology.

Run the following after editing a catalog:

```sh
python3 Scripts/generate-resources.py
python3 Scripts/validate-localizations.py
python3 Scripts/validate-windows.py
```

The generator emits macOS `.strings` and `.stringsdict` files and Windows `.resw` files. Generated files are committed for offline builds and must not be edited directly. `--check` compares every generated byte without changing files. Native builds and CI validate these outputs.

Windows resource identifiers are deterministic hashes of the shared message key. Placeholder conversion handles sequential and positional Apple arguments. Dynamic Windows messages and plural selection use the same embedded JSON catalogs. The language selected in settings takes effect on restart.

Platform terminology can differ. For example, the shared `Show in Finder` key uses a Windows override referring to File Explorer. Repository paths, branch names, commit messages, and original Git diagnostics are never translated. Application-owned error headings are localized.

Preserve interpolation placeholders such as `%@`, `%lld`, and positional variants. Translate whole messages so word order can change. Keep Chinese separated from Latin text and numbers by spaces. Keep every language's keys complete. Russian plural entries include `one`, `few`, `many`, and `other`.

Validate compiler-extracted macOS keys after building:

```sh
python3 Scripts/validate-localizations.py --extracted-directory build/DerivedData/Build/Intermediates.noindex/FoldGit.build
```

For layout review, check the minimum window size, dialogs, commit editor, comparison controls, high contrast, and multiple display scales. Russian, French, and Spanish exercise long labels. Native UI must wrap or reflow controls rather than truncate operation names.
