少数派｜FoldGit 宣传文案

【标题】
开发者自荐｜FoldGit：一个小巧、简洁的原生 macOS Git 客户端

【正文】
现在我写代码，基本都交给 Agent 了。但真正要放进生产环境的代码，还是得自己看一遍：改了哪些文件、动了哪些逻辑，有没有改到预期之外。

这时候，我常常只是想看改动、做提交，并不需要完整的编辑环境。为了这几步再打开功能繁多、启动和运行都有负担的编辑器或 IDE，有时反而打断节奏。对我来说，轻量的 Git 客户端可能会比以前打开得更频繁。

我想找一款这样的客户端：原生开发，适配最新 macOS 的界面风格，体积小、界面简洁，操作符合直觉，而且免费开源。暂时没找到合适的，就做了 FoldGit。

它把多个仓库收进同一个窗口。导入目录，里面的仓库会自动成组；不同位置的仓库也能放进自定义分组。整理只发生在应用里，不会移动磁盘上的文件夹。不活跃的仓库还能再折叠一层，让正在做的项目留在眼前。

工作树跟在所属仓库下面，带着分支名显示。支持新建、移动、锁定和移除，也可以通过「完成工作树」合并到目标分支并清理，方便同时处理不同任务。

打开仓库后，先通过目录树了解涉及哪些文件，再展开单栏或并排差异逐行查看。确认改动后，可以按目录或代码块暂存、提交。提交历史、分支、标签、Stash、推送与拉取这些日常操作也已具备。

macOS 版用 SwiftUI 与 AppKit 原生实现，采用 macOS 26 液态玻璃与系统控件，支持亮暗色、原生菜单和快捷键。当前 0.2.0 的 macOS 安装包约 6.2 MB，免费使用，采用 MIT 许可证开源。

需要 macOS 26 及以上、Apple Silicon Mac，并已安装 Git。官网有手册和下载入口，欢迎试用并反馈。

另有 Windows 版，目前是最简实现，欢迎参与完善。

官网： https://foldgit.com
源码： https://github.com/dufu1991/foldgit
