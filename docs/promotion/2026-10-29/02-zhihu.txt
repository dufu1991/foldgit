知乎｜FoldGit 宣传文案

【标题】
想找个小巧、简洁的原生 Git 客户端，我做了 FoldGit

【正文】
代码交给 Agent 写之后，还需要经常打开 IDE 吗？对我来说，如果只是看改动、暂存和提交，未必需要。

现在我写代码基本都交给 Agent，但要进生产环境的代码，还是得自己检查。为了看一次差异就启动完整的编辑器或 IDE，有时会带来额外等待。轻量 Git 客户端的使用频率，反而可能比以前更高。

我想要的是原生开发、适配最新 macOS 风格、体积小、界面简洁、操作符合直觉，而且免费开源的工具。暂时没找到合适的，就做了 FoldGit。

第一，把仓库留在侧边栏。导入目录可以自动分组，也能把不同位置的仓库放进自定义分组，不会移动实际文件夹。不活跃仓库可以折叠起来。

第二，让工作树跟着仓库走。关联工作树显示在所属仓库下，并标注分支名，支持新建、移动、锁定、移除，以及合并后清理。

第三，先看范围，再看细节。通过目录树了解改了哪些文件，再展开单栏或并排差异，按目录或代码块暂存、提交。历史搜索、分支与标签比较、推送、拉取和 Stash 也已具备。

macOS 版使用 SwiftUI 与 AppKit 实现，采用 macOS 26 液态玻璃与系统控件，支持亮暗色和原生快捷键。0.2.0 的 macOS 安装包约 6.2 MB，采用 MIT 许可证开源。需要 macOS 26 及以上、Apple Silicon Mac 和 Git。

欢迎体验，也欢迎反馈查看改动和整理仓库时不顺手的地方。

另有 Windows 版，目前是最简实现，欢迎参与完善。

官网： https://foldgit.com
源码： https://github.com/dufu1991/foldgit
