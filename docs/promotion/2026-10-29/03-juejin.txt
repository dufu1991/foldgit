掘金｜FoldGit 宣传文案

【标题】
开源自荐：FoldGit，采用 macOS 26 原生风格的 Git 客户端

【正文】
现在我写代码，基本都交给 Agent，但生产代码提交前，仍然要自己检查改动范围和具体逻辑。

如果只是看差异、暂存和提交，我不想每次都打开完整的编辑器或 IDE。编辑环境功能越来越多，单纯查看改动时，轻量 Git 客户端反而可能更常用。

所以做了 FoldGit：原生开发，适配最新 macOS 风格，体积小、界面简洁、操作符合直觉，而且免费开源。它把多仓库、工作树和改动查看放进同一个窗口。

一、找到项目。
仓库常驻侧边栏，导入目录可以自动分组，也能建立跨目录的自定义分组，不会移动文件夹。不活跃仓库可以折叠，关联工作树则显示在所属仓库下，并标注分支名。

二、检查改动。
工作区和历史记录支持目录树，目录与差异各自展开。先看涉及哪些文件，再展开单栏或并排差异。确认之后，可以按目录或代码块暂存，把需要的改动组成一次提交。

三、提交并收尾。
支持修改上次提交、撤销提交、推送、拉取、Stash 和历史搜索。工作树支持新建、移动、锁定和移除；任务完成后，可合并到目标分支并清理。

macOS 版使用 SwiftUI 与 AppKit 原生实现，采用 macOS 26 液态玻璃与系统控件，不含 Electron。0.2.0 的 macOS 安装包约 6.2 MB，采用 MIT 许可证开源。运行需要 macOS 26 及以上、Apple Silicon Mac，并已安装 Git。

欢迎试用并反馈。

另有 Windows 版，目前是最简实现，欢迎参与完善。

官网： https://foldgit.com
源码： https://github.com/dufu1991/foldgit
