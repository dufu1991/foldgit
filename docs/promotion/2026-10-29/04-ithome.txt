IT 之家｜FoldGit 宣传文案

【标题】
开发者自荐：FoldGit，小巧简洁、免费开源的原生 macOS Git 客户端

【正文】
代码基本交给 Agent 写之后，我更需要一个轻量的改动查看窗口。生产代码仍要自己检查，但只看差异、做提交时，不必每次都打开完整的编辑器或 IDE，Git 客户端反而可能更常用。

所以做了 FoldGit：原生开发，适配最新 macOS 风格，体积小、界面简洁、操作符合直觉，而且免费开源。

仓库可以分组折叠，不移动实际文件夹；工作树跟在所属仓库下，显示分支名。支持目录树、单栏和并排差异、代码块暂存，以及提交、分支、推送、拉取和 Stash。

macOS 版采用 macOS 26 原生风格，0.2.0 安装包约 6.2 MB，MIT 开源。需要 macOS 26 及以上、Apple Silicon Mac 和 Git。

另有 Windows 版，目前是最简实现，欢迎参与完善。

官网： https://foldgit.com
源码： https://github.com/dufu1991/foldgit
