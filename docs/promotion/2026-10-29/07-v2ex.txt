V2EX｜FoldGit 宣传文案

【标题】
开源自荐：FoldGit，原生、小巧、界面简洁的 macOS Git 客户端

【正文】
现在写代码，基本都交给 Agent 了。但要进生产环境的代码，还是得自己检查改了什么、有没有越界。

如果只是看改动、暂存和提交，我不想每次都打开功能繁多、偶尔还有些卡顿的编辑器或 IDE。轻量 Git 客户端的使用频率，反而可能会更高。

所以做了 FoldGit：原生开发，适配 macOS 26 风格，小巧、界面简洁、操作直觉，而且免费开源。

主要功能：

• 仓库按目录或自定义分组，不移动文件夹；不活跃仓库可以折叠。
• 自动发现工作树，显示所属仓库和分支名，支持新建、移除及合并后清理。
• 目录树、单栏和并排差异、按目录或代码块暂存，以及提交、历史搜索、分支比较、Stash、推送与拉取。

0.2.0 的 macOS 安装包约 6.2 MB。需要 macOS 26 及以上、Apple Silicon Mac 和 Git。欢迎试用并反馈。

另有 Windows 版，目前是最简实现，欢迎参与完善。

官网： https://foldgit.com
源码： https://github.com/dufu1991/foldgit
