小红书｜FoldGit 宣传文案

【标题】
小巧简洁的原生 Git 客户端

【正文】
现在代码基本交给 Agent 写，但生产代码还是要自己看一遍。

如果只是看改动、暂存和提交，就不想每次都打开完整的编辑器或 IDE。轻量 Git 客户端，反而可能会比以前更常用。

所以做了 FoldGit：原生开发，适配最新 macOS 风格，小巧、界面简洁、操作直觉，而且免费开源。

仓库可以分组折叠，工作树跟着所属仓库显示。先看目录树，再展开并排差异，确认后再暂存提交，不用搬动磁盘上的文件夹。

Mac 安装包约 6.2 MB，需 macOS 26 及以上、Apple Silicon Mac 和 Git。

另有 Windows 版，目前是最简实现，欢迎参与完善。

官网： https://foldgit.com
源码： https://github.com/dufu1991/foldgit
