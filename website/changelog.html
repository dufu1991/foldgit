更新日志Changelog

每个版本，都让日常操作更顺手。Small updates for a smoother everyday workflow.

0.3.0

最新版本Latest 2026-10-30
  • macOS 新增 Git 命令日志，支持搜索、筛选、复制与导出。
  • macOS 改进操作失败提示，可查看关联命令日志及自动获取、工作树错误详情。
  • macOS 修复手动获取成功后自动获取警告未清除的问题。
  • Add Git command logs on macOS with search, filtering, copying and export.
  • Improve failure messages on macOS with access to related command logs and automatic fetch and worktree error details.
  • Fix stale automatic fetch warnings after a successful manual fetch on macOS.

0.2.0

2026-10-29
  • macOS 新增改动目录树，工作区与提交历史可独立展开目录和差异，并按整个目录暂存或取消暂存。
  • macOS 新增文件暂存与取消暂存动画，遵循系统减少动态效果设置，并优化文件操作按钮。
  • macOS 改进仓库分组与非活跃仓库的折叠操作，精简 macOS 与 Windows 的工具栏、搜索及操作文案。
  • macOS 新增启动时检查更新与菜单中的手动检查，发现新版本后可打开发布页下载。
  • Add change directory trees on macOS for the working copy and commit history, with independent folder and diff expansion and directory-wide staging and unstaging.
  • Add file staging and unstaging animations on macOS that respect Reduce Motion, and refine file action buttons.
  • Improve folding of repository groups and inactive repositories on macOS, and simplify toolbar, search and action labels on macOS and Windows.
  • Add update checks at launch and a manual menu command on macOS, with a link to download newer releases.

0.1.1

2026-10-28
  • 新增 macOS 原生菜单与快捷键，快速操作仓库、分支和提交。

0.1.0

2026-10-28
  • 首次发布，支持按目录或分组管理多个仓库与工作树。
  • 支持提交历史、差异查看、暂存、提交及分支同步。
  • 提供 macOS 原生应用与 Windows x64、ARM64 安装包。
  • First release with repositories and worktrees organized by folder or group.
  • Browse history and diffs, stage and commit changes, and sync branches.
  • Available as a native macOS app and Windows x64 and ARM64 installers.
