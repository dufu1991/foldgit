安装Install

  1. 在 GitHub Releases 下载 FoldGit-…-macOS-arm64.dmg。
  2. 打开 DMG，把 FoldGit 拖进「应用程序」。
  3. 需要 macOS 26 及以上的 Apple Silicon Mac，并已安装 Git。没有 Git 的话，在终端运行 xcode-select --install。

首次打开提示“已损坏”或“无法验证开发者”？FoldGit 暂未使用 Apple 开发者证书签名，macOS 会拦截。在终端执行下面的命令后再打开即可：

xattr -dr com.apple.quarantine /Applications/FoldGit.app
  1. Download FoldGit-…-macOS-arm64.dmg from GitHub Releases.
  2. Open the DMG and drag FoldGit into Applications.
  3. Requires an Apple Silicon Mac on macOS 26 or later, with Git installed. If Git is missing, run xcode-select --install in Terminal.

“FoldGit is damaged” or “cannot be verified” on first launch? FoldGit is not yet signed with an Apple Developer certificate, so macOS blocks it. Run this in Terminal, then open it again:

xattr -dr com.apple.quarantine /Applications/FoldGit.app
02

添加仓库Add repositories

点击侧边栏顶部的 +：

  • 添加本地仓库或目录：选一个仓库，或一个包含多个仓库的目录。选目录时，其中的仓库会自动收成一组。
  • 克隆远程仓库：填入地址，选好保存位置，克隆完成后自动添加并选中。

Click + at the top of the sidebar:

  • Add Local Repository or Directory — pick one repository, or a folder that contains several. A folder becomes a group automatically.
  • Clone Remote Repository — enter the URL and choose where to save it. The clone is added and selected when it finishes.
03

整理侧边栏Organize the sidebar

  • 分组：在 + 菜单中选「新建分组」，或多选仓库后右键「将所选仓库新建为分组」。分组只是整理方式，不会移动文件夹。
  • 不常用的仓库：右键「设为不活跃」，它会收进分组底部的二级折叠里。
  • 改名：右键修改「仓库显示名称」，只影响侧边栏，不改文件夹名。
  • 查找与排序：顶部搜索框按名称过滤；旁边的排序按钮可按名称、最近打开、最近修改或最近添加排序，也可以直接拖动调整顺序。
  • Groups — choose New Group from the + menu, or select several repositories and right-click New Group with Selection. Groups never move folders on disk.
  • Rarely used repositories — right-click Mark as Inactive to tuck one into the folded section at the bottom of its group.
  • Rename — set a Repository Display Name from the context menu. Only the sidebar label changes.
  • Find and sort — the search field filters by name; the sort button orders by name, recently opened, modified or added. You can also drag to reorder.
04

查看与提交改动Review and commit

  1. 选中仓库，点提交列表顶部的「未提交的更改」。
  2. 逐个文件查看差异。每个代码块右侧的 + 可以单独暂存这一块，− 取消暂存；也可以用底部的「全部暂存」。
  3. 在「提交信息」里写好说明，按 ⌘↩ 或点「提交」。勾选「修改上次提交」可以改写最近一次提交。

差异显示默认「自动」：窗口够宽时并排，窄时单栏。也可以在底部手动切换。

  1. Select a repository and click Uncommitted Changes at the top of the commit list.
  2. Read the diff file by file. The + beside each hunk stages just that hunk, − unstages it; or use Stage All at the bottom.
  3. Write a Commit Message and press ⌘↩ or click Commit. Tick Amend to rewrite the latest commit.

Diff layout defaults to Automatic: side by side when the window is wide enough, unified when it is not. You can switch it at the bottom.

05

浏览历史Browse history

  • 点击任意提交，右侧显示它改了什么。
  • ⌘F 搜索提交，可按作者、邮箱或提交信息查找。
  • 搜索框旁的菜单可以在「当前分支」和「全部提交」之间切换。
  • 提交列表底部的分支图标用来显示或隐藏提交图。
  • Click any commit to see what it changed.
  • ⌘F searches commits by author, email or message.
  • The menu beside the search field switches between Current Branch and All Commits.
  • The branch icon at the bottom of the list shows or hides the commit graph.
06

分支与同步Branches and sync

都在窗口顶部的工具栏里：

  • 选择分支：切换、合并到当前分支、重命名或删除分支。
  • 新建分支、查看标签：创建分支，浏览和管理标签。
  • 比较分支或标签：选两个版本，查看它们之间的全部差异。
  • 抓取 / 拉取 / 推送：与远程同步。抓取只下载更新，不会合并。
  • 打开方式：在终端、编辑器或访达中打开当前仓库。

Everything lives in the toolbar:

  • Select Branch — switch, merge into the current branch, rename or delete.
  • Create New Branch and Show Tags — create branches, browse and manage tags.
  • Compare Branches or Tags — pick two revisions and see everything between them.
  • Fetch / Pull / Push — sync with the remote. Fetch only downloads; it never merges.
  • Open in — open the repository in Terminal, your editor or Finder.
07

工作树Worktrees

  1. 在仓库上右键「启用工作树」。（设置 → 仓库中的全局开关默认已打开。）
  2. 右键「新建工作树」，选新分支或已有分支。新工作树会折叠显示在仓库下方。
  3. 做完后右键「完成工作树」：选择目标分支，合并提交，再按需移除目录、删除源分支。

遇到冲突时，可以在弹窗里比较两侧版本、选择保留哪一边，或用外部编辑器处理后继续。

  1. Right-click a repository and choose Enable Worktrees. (The global switch under Settings → Repository is on by default.)
  2. Right-click New Worktree and pick a new or existing branch. It appears folded beneath the repository.
  3. When you are done, right-click Finish Worktree: choose the target branch, merge, then optionally remove the folder and delete the source branch.

On conflicts, compare both sides in the sheet, keep one, or resolve in an external editor and continue.

08

贮藏Stash

在「未提交的更改」底部点「贮藏更改」，把手上的修改先收起来；之后从工具栏「查看贮藏的更改」中查看并恢复。

Click Stash All Changes under Uncommitted Changes to set your work aside, then view and restore it from Show Stashed Changes in the toolbar.

09

设置Settings

按 ⌘, 打开。常用的几项：

  • 界面语言与外观：八种语言，亮色、暗色或跟随系统。改语言后需重启应用。
  • 自动抓取：为每个仓库单独设置抓取间隔。
  • 代码显示：差异布局、字号、长行自动换行。
  • 打开方式：固定常用的编辑器或终端，它们会排在菜单最前面。

Press ⌘,. The ones you will likely touch:

  • Language and appearance — eight languages; light, dark or automatic. Restart after changing the language.
  • Automatic Fetch — a fetch interval per repository.
  • Code Display — diff layout, font size, wrapping long lines.
  • Open in — pin your editor or terminal so it comes first in the menu.
